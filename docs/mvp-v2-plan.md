# MVP v2 Plan: 임신부터 초기육아까지 부모 케어 앱

> 목적: 기존 예방접종 MVP를 버리지 않고, 임신 단계부터 출산 후 초기육아까지 이어지는 가장 작은 테스트 가능한 MVP로 확장한다.

## 1. MVP 한 줄 정의

임신 주차/출산 예정일을 입력하면 지금 해야 할 체크리스트와 혜택을 보여주고, 출산 후에는 아이 예방접종·검진·상태체크로 이어지는 초보 부모용 로컬 MVP.

## 2. 이번 MVP의 목표

이번 버전은 완성 서비스가 아니라 `방향 검증용 기능 테스트`다.

검증할 질문:

1. 초보 부모가 임신/출산/초기육아 할 일을 한곳에서 보는 구조가 유용한가?
2. 임신 단계와 출산 후 접종 기능이 자연스럽게 이어지는가?
3. 정부지원/지역 혜택 체크리스트가 앱 재방문 이유가 되는가?
4. 향후 광고/추천 BM을 붙일 자리가 자연스럽게 보이는가?

## 3. 이번 MVP에 포함할 것

### A. 시작 모드 선택

첫 화면에서 사용자가 현재 상태를 고른다.

- 임신 중이에요
- 아이가 태어났어요

`아이가 태어났어요`는 기존 자녀 등록/접종 기능으로 연결한다.

### B. 임신 프로필 등록

입력 항목:

- 출산 예정일 또는 현재 임신 주차
- 거주지역, 선택값
- 출산 순서, 선택값: 첫째/둘째 이상

MVP에서는 계정/로그인 없이 localStorage에 저장한다.

### C. 임신 대시보드

보여줄 정보:

- 현재 임신 주차
- 출산 예정일까지 D-day
- 이번 시기 할 일
- 곧 챙길 일
- 완료한 체크리스트 개수

### D. 체크리스트 4종

#### 1. 임신 초기 필수 체크

- 임신확인서 받기
- 임산부 등록
- 정부24 맘편한 임신 신청
- 보건소 혜택 확인
- 엽산제 지원 확인
- 철분제 지원 확인
- 국민행복카드 신청
- 산후조리원 알아보기

#### 2. 주차별 검사/진료 체크

MVP에서는 정교한 전체 의학 스케줄이 아니라 대표 구간만 넣는다.

- 5~7주: 임신 확인/초음파
- 8~12주: 산전 기본검사
- 11~13주: 1차 기형아 검사
- 16~18주: 2차 기형아 검사
- 20주 전후: 정밀 초음파
- 24~28주: 임신성 당뇨 검사
- 35~37주: 막달 검사/분만 준비

정확한 의료 기준 검수는 이후 단계로 미룬다.

#### 3. 출산 준비 체크

- 산후조리원 예약
- 산후관리사 업체 알아보기
- 출산가방 준비
- 아기용품 기본 준비
- 카시트 확인
- 병원 서류/산모수첩 준비
- 보호자 연락망 정리

#### 4. 혜택/지원 체크

- 국민행복카드
- 임신·출산 진료비 지원
- 첫만남이용권
- 산후관리사 정부지원
- 부모급여
- 아동수당
- 지역 출산축하금
- 지역 산후조리비
- 임산부 교통/생활 혜택
- KTX/SRT 임산부 할인

MVP에서는 지역별 자동 정확 매칭은 하지 않는다. 대신 `지역별 확인 필요` 태그와 공식 확인 안내 문구를 표시한다.

### E. 출산 후 전환

임신 대시보드에서 버튼 제공:

- 출산했어요 / 아이 등록하기

누르면 기존 자녀 등록 기능으로 이동한다.

### F. 기존 출산 후 기능 유지

- 자녀 여러 명 등록
- 생년월일 기준 예방접종 일정 생성
- 영유아 검진 일정 생성
- .ics 캘린더 내보내기
- 접종/검진 완료 체크
- 접종 후 24시간 상태 체크
- JSON 백업/복원

## 4. 이번 MVP에서 제외할 것

복잡도를 낮추기 위해 제외한다.

- 로그인
- 서버/DB/Supabase
- 실제 정부 API 연동
- 지역구별 자동 혜택 크롤링
- 푸시 알림
- 결제
- 실제 광고 SDK
- 상품 구매 링크 자동화
- 의료 기준 완전 검수
- 가족 공유
- 병원 예약 연동

## 5. 광고 BM은 어떻게 자리만 잡을까

이번 MVP에서는 실제 광고를 붙이지 않는다. 대신 `추천 아이템 자리`만 만든다.

예:

- 임신 초기: 엽산, 산모수첩 케이스
- 임신 중기: 바디필로우, 철분제 복용 기록 도구
- 출산 준비: 기저귀, 물티슈, 젖병, 카시트, 체온계
- 접종 후: 아기 체온계, 수유 기록 도구

표시는 이렇게 한다.

`나중에 추천/제휴 영역으로 확장 가능`

## 8. 성공 기준

이번 MVP가 성공하려면 아래가 되면 된다.

- 사용자가 `임신 중이에요`를 선택할 수 있다.
- 출산 예정일 또는 주차를 입력할 수 있다.
- 현재 임신 주차와 D-day가 표시된다.
- 임신 관련 체크리스트가 카테고리별로 보인다.
- 체크 완료 상태가 새로고침 후에도 유지된다.
- 혜택/지원 항목에 `공식 확인 필요` 안내가 보인다.
- `출산했어요/아이 등록하기`로 기존 접종 기능으로 넘어갈 수 있다.
- 기존 빌드와 로직 테스트가 깨지지 않는다.

## 9. 구현 순서

1. 데이터 타입과 기본 임신 체크리스트 템플릿 추가
2. AppData에 임신 프로필/체크상태 추가 및 기존 저장 데이터 마이그레이션 처리
3. 시작 모드 선택 UI 추가
4. 임신 프로필 등록 폼 추가
5. 임신 대시보드 추가
6. 체크리스트 완료/해제 기능 추가
7. 기존 출산 후 기능으로 연결
8. 빌드/로직 테스트 실행
9. GitHub 커밋/푸시

## 10. 주의 문구
