# Baby Vaccine MVP

신생아/영유아 예방접종·검진 일정 관리 기능테스트용 웹앱 MVP입니다.

## 주요 기능

- 자녀 여러 명 등록
- 자녀별 예방접종/영유아 검진 일정 자동 생성
- 다가오는 일정 확인
- 접종/검진 완료 체크
- 접종 완료 24시간 후 상태 체크 카드
- 접종열/컨디션/수유/접종 부위/증상 기록
- JSON 백업/복원 및 전체 초기화
- localStorage 기반 로컬 저장

## 실행

```bash
npm install
npm run dev
```

브라우저에서:

```txt
http://localhost:5173/
```

## 검증

```bash
npm run build
npm run test:logic
```

## 주의

이 앱은 의료 진단을 제공하지 않습니다. 접종/검진 일정과 아이 상태에 대한 최종 판단은 반드시 의료진 또는 공식 기관 안내를 확인해야 합니다.
